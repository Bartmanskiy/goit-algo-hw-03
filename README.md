## Description

This repository contains Python exercises focused on working with dates, random number generation, sets, lists, input validation, and basic error handling.
The project includes two independent tasks that demonstrate practical use of Python's standard library and fundamental programming concepts.

## Technologies

* Python
* `datetime` — date parsing and date calculations
* `random` — random number generation
* Sets and lists
* Exception handling
* Functions

## Functionality

### Date Difference

The `homework_1.py` script implements a function that calculates the number of days between a specified date and the current date.
The function:
* accepts a date in `YYYY-MM-DD` format;
* converts the input string into a date;
* calculates the difference between the specified date and the current date;
* handles invalid date formats using exception handling.

### Lottery Number Generator

The `homework_2.py` script implements a function for generating a specified quantity of unique random lottery numbers within a given range.
The function:
* validates the minimum and maximum values;
* checks whether the requested quantity can be generated;
* generates unique numbers using a `set`;
* sorts the generated numbers before returning them;
* returns an empty list when the input parameters are invalid.
